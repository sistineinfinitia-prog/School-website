Theme A.1 SL / HL Computer Architecture
2 Marks

State one architectural difference between a central processing unit (CPU) and a graphics processing unit (GPU).

Official Mark Scheme [Max 2 Marks]
  • CPU: Optimized for sequential processing and contains relatively few, powerful, low-latency execution cores. [1 mark]
  • GPU: Designed for parallel execution and contains hundreds or thousands of smaller cores to execute repetitive matrix math concurrently. [1 mark]
Examiner Tip: Do not accept vague statements like "a GPU is only for video games". The question tests architectural differences (sequential vs parallel cores).
Theme A.1 SL / HL Processor Cycle
4 Marks

Outline the four distinct stages of the machine fetch-decode-execute cycle, referring to the registers involved.

Official Mark Scheme [Max 4 Marks]
  • Fetch: The address in the Program Counter (PC) is passed to the MAR; the instruction is fetched from RAM into the MDR; the PC is incremented. [1 mark]
  • Copy: The instruction is copied from MDR to the Current Instruction Register (CIR). [1 mark]
  • Decode: The Control Unit (CU) decodes the opcode and determines what ALU operations or memory reads are required. [1 mark]
  • Execute: The ALU performs the operation or transfers data to registers/memory; status flags are updated. [1 mark]
Examiner Tip: Always state that the Program Counter (PC) is incremented after fetching.
Theme A.1 SL / HL Primary Memory
3 Marks

Distinguish between read-only memory (ROM) and random-access memory (RAM) in terms of volatility, mutability, and purpose.

Official Mark Scheme [Max 3 Marks]
  • Volatility: RAM is volatile (loses contents on power loss); ROM is non-volatile (retains data indefinitely). [1 mark]
  • Mutability: RAM is read-write; ROM is typically read-only during standard operations. [1 mark]
  • Purpose: RAM holds the currently executing programs and operating system working data; ROM holds the bootstrap/BIOS start-up loader. [1 mark]
Theme A.1 SL / HL Operating Systems
3 Marks

Explain why an operating system uses hardware interrupts rather than polling to detect keyboard input.

Official Mark Scheme [Max 3 Marks]
  • Polling forces the processor to repeatedly query the device, consuming clock cycles and power when no key is pressed. [1 mark]
  • An interrupt sends an electrical signal only when a key event occurs, leaving the CPU free to execute other processes. [1 mark]
  • The CPU pauses the current process, executes the Interrupt Service Routine (ISR) with minimal latency, and returns to execution. [1 mark]
Theme A.2 SL / HL Data Transmission
3 Marks

Describe the function of packet switching across the Internet, referring to headers, routing, and reassembly.

Official Mark Scheme [Max 3 Marks]
  • The data payload is broken down into small, numbered packets, each tagged with destination IP, sender IP, and sequence numbers in the header. [1 mark]
  • Routers inspect the destination IP and forward each packet independently along the most efficient available route. [1 mark]
  • The recipient node uses packet sequence numbers to reorder and reassemble the original message, requesting retransmission for missing packets. [1 mark]
Theme A.2 HL Only Cryptography
3 Marks

Compare symmetric and asymmetric encryption, explaining why asymmetric keys are preferred for key exchange over insecure channels.

Official Mark Scheme [Max 3 Marks]
  • Symmetric encryption uses a single shared secret key for both encryption and decryption. [1 mark]
  • Asymmetric encryption uses a mathematically linked key pair: a public key for encryption and a private key for decryption. [1 mark]
  • Asymmetric eliminates the key distribution problem: the private key is never transmitted across the network, preventing interception. [1 mark]
Theme A.3 SL / HL Relational Schemas
3 Marks

Explain the role of primary keys and foreign keys in maintaining referential integrity across relational database tables.

Official Mark Scheme [Max 3 Marks]
  • A primary key uniquely identifies each record/tuple within its home table, preventing duplicate entries. [1 mark]
  • A foreign key is an attribute in one table that references the primary key in another table, establishing a relationship. [1 mark]
  • Referential integrity ensures a foreign key value cannot exist without a corresponding valid primary key record in the parent table. [1 mark]
Theme B.1 SL / HL Algorithmic Design
4 Marks

Define abstraction and decomposition. Explain how each technique reduces cognitive complexity when developing large software systems.

Official Mark Scheme [Max 4 Marks]
  • Decomposition: Breaking a complex problem into smaller, self-contained sub-problems or functions that can be solved independently. [1 mark]
  • Benefit: Enables team parallel development, modular testing, and clear subroutine interfaces. [1 mark]
  • Abstraction: Filtering out irrelevant implementation details to focus on high-level behaviors and inputs/outputs. [1 mark]
  • Benefit: Prevents information overload and allows code reuse across different parts of a program. [1 mark]
Theme B.2 / B.4 SL / HL Memory Allocation
4 Marks

Compare static arrays with dynamic linked lists with respect to memory allocation, insertion complexity, and random access speed.

Official Mark Scheme [Max 4 Marks]
  • Memory Allocation: Arrays have a fixed size declared at compile time in contiguous memory; linked lists allocate nodes dynamically anywhere in the heap. [1 mark]
  • Insertion: Arrays require shifting subsequent elements (O(n)); linked lists insert in O(1) time once the pointer reference is found. [1 mark]
  • Random Access: Arrays support instant O(1) index access using base address + index calculation; linked lists require O(n) pointer traversal from the head node. [1 mark]
  • Overhead: Linked lists require additional memory for pointer addresses with each data node. [1 mark]
Theme B.3 SL / HL Object-Oriented Programming
3 Marks

Explain the concept of encapsulation in object-oriented programming and outline two advantages it provides to software maintainability.

Official Mark Scheme [Max 3 Marks]
  • Encapsulation bundles data (attributes) and methods that operate on that data inside a class, while restricting direct access using private modifiers. [1 mark]
  • Advantage 1 (Data Protection): Prevents accidental external modification; state changes must pass through validated getter/setter methods. [1 mark]
  • Advantage 2 (Maintainability): Internal class implementations can be updated or optimized without breaking external client code that calls public methods. [1 mark]
Paper 3 HL Only Case Study: Chatbots
4 Marks

Explain why large language model chatbots are susceptible to "hallucinations", and describe two mitigation strategies used by developers.

Official Mark Scheme [Max 4 Marks]
  • Cause: LLMs generate text based on statistical token probabilities rather than semantic reasoning or grounded fact verification. [2 marks]
  • Mitigation 1 (RAG): Retrieval-Augmented Generation retrieves vetted documents from an external vector database to ground the prompt in verified facts. [1 mark]
  • Mitigation 2 (RLHF): Reinforcement Learning from Human Feedback trains reward models that penalize fabricated responses and encourage cautious answers. [1 mark]
Theme B.1 / B.2 SL / HL Algorithm Efficiency
3 Marks

Compare the worst-case time complexity of linear search and binary search, explaining the precondition required to execute binary search.

Official Mark Scheme [Max 3 Marks]
  • Precondition: The array or list must be strictly sorted prior to running binary search. [1 mark]
  • Linear Search: O(n) worst-case time complexity because every element must be inspected if the target is at the end or absent. [1 mark]
  • Binary Search: O(log n) worst-case time complexity because the search space is halved after each comparison. [1 mark]
