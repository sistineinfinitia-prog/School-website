THEME A.1 SL / HL Computer Architecture
2 Marks
State one architectural difference between a central processing unit (CPU) and a graphics processing unit (GPU).
Official Mark Scheme [Max 2 Marks]
  • CPU: Optimized for sequential processing; has few powerful, low-latency execution cores. [1 mark]
  • GPU: Designed for parallel execution; has many smaller cores executing operations concurrently. [1 mark]
Tip: Answer must address architecture (cores / parallel vs sequential), not just application ("games").
