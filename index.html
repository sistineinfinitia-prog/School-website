Theme A Systems, Networks, Databases & Machine Learning
Ready • 70 Files

Computer architecture, machine instruction cycle (Fetch-Decode-Execute), logic gates, memory hierarchy, packet-switched networks, relational databases (1NF to 3NF & SQL), and machine learning fundamentals.

  • A1
    Computer Fundamentals CPU architecture (ALU, CU, registers, buses), primary/secondary memory, fetch-decode-execute cycle, truth tables, OS scheduling, and translators.
  • A2
    Networks TCP/IP & OSI models, packet switching, routing, DNS, firewalls, encryption, and the interactive 85-minute networking studio.
  • A3
    Databases & SQL Entity-relationship diagrams, primary/foreign keys, normalization (1NF, 2NF, 3NF), SQL DDL/DML queries, and ACID transactions.
  • A4
    Machine Learning Supervised, unsupervised, and reinforcement learning, linear regression, classification, neural networks, and algorithmic ethics.

Theme B Computational Thinking, Python & OOP
Ready • 48 Files

Problem decomposition, algorithmic trace tables, searching and sorting algorithms, Python programming constructs, and Object-Oriented Programming (encapsulation, inheritance, polymorphism).

  • B1
    Computational Thinking Problem specification, abstraction, decomposition, flowcharts, pseudocode conventions, and trace tables.
  • B2
    Programming Constructs Variables, strings, 1D/2D arrays, file I/O, modular subroutines, Big-O complexity, linear/binary search, and bubble/selection sort.
  • B3
    Object-Oriented Programming Classes, constructors, encapsulation, inheritance, polymorphism, aggregation, and UML class diagrams in Python.

Theme A.1 SL / HL Computer Architecture
2 Marks

State one architectural difference between a central processing unit (CPU) and a graphics processing unit (GPU).

Official Mark Scheme [Max 2 Marks]
  • CPU: Optimized for sequential processing; contains relatively few powerful, low-latency execution cores. [1 mark]
  • GPU: Designed for parallel execution; contains hundreds or thousands of smaller cores executing operations concurrently. [1 mark]
Examiner Tip: Answer must address processor architecture (cores / parallel vs sequential execution), not just end-user application ("video games").
